## Short Description
A spaced repetition flashcard app with user accounts, custom decks, and smart review scheduling.

## Full Description
Personal learning tool built around the SRS (Spaced Repetition System) method — the same technique used by apps like Anki. You create decks, add question/answer cards, and study them. After each card you rate yourself (Again / Hard / Good / Perfect), and the app schedules the next review accordingly — from 3 minutes up to 1 day. User accounts and all data are handled by Supabase, so your progress is saved in the cloud. Includes statistics to track how well you're retaining knowledge.
